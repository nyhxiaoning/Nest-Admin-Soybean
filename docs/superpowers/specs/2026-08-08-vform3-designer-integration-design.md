# VForm 3 表单设计器集成设计

## 概述

重新实现前端 `/tool/build` 页面，按 VForm 3 官方推荐方式将 `vform3-builds` 集成到现有 Vue 3 管理后台。设计器将直接铺满后台主内容区，不再显示 Naive UI 卡片、页面标题、加载按钮或调试信息。

## 目标

- `/tool/build` 打开后立即显示完整的 VForm 3 三栏设计器。
- 使用 VForm 3 官方推荐的 Vue 插件注册和静态 CSS 引入方式。
- 设计器高度自适应当前后台内容区，左侧组件、中间画布、右侧属性面板各自正常滚动。
- 不改变现有菜单、顶部标签栏、主题和其他 Naive UI 页面。

## 非目标

- 本次不开发 VForm 自定义组件。
- 不增加表单 JSON 的后端保存、版本管理或发布流程。
- 不修改 VForm 3 依赖包源码。
- 不通过 iframe、CDN 或独立 Vue 子应用加载设计器。

## 选定方案

采用“全局注册 VForm 3 插件，页面直接渲染设计器”方案。

前端应用初始化时：

1. 引入并注册 `ElementPlus`。
2. 引入并注册 `VForm3`。
3. 静态引入 `element-plus/dist/index.css`。
4. 静态引入 `vform3-builds/dist/designer.style.css`。

`/tool/build` 页面在同一个 Vue 应用上下文中直接使用：

```vue
<v-form-designer ref="designerRef" />
```

这与 VForm 3 官方文档的 Vue 3 项目集成方式一致。

## 组件与文件变更

### 应用入口

在现有 Vue 应用创建流程中安装 `ElementPlus` 和 `VForm3`。注册顺序为 Element Plus 在前、VForm 3 在后，以满足 VForm 内部 Element Plus 组件依赖。

全局引入仅包含依赖库官方样式，不在入口中添加页面尺寸或布局覆盖。

### `/tool/build` 页面

替换现有动态 UMD 加载实现，删除：

- 运行时 `fetch` CSS。
- 手动往 `document.head` 注入样式。
- 二次 `Vue.createApp()` 和子应用挂载。
- “加载/重新加载”按钮、加载态、错误卡片和调试输出。
- 外层 `NCard` 和固定 `700px` 高度。

页面根容器将使用 `width: 100%`、`height: 100%`、`min-height: 0` 和 `overflow: hidden`。VForm 设计器根节点同样填满父容器，不设置额外外边距和内边距。

## 布局与样式边界

- 后台侧边栏和顶部标签栏仍由现有 layout 控制。
- VForm 仅占据路由内容区，不使用 `100vh`，避免把顶部标签栏高度重复计入。
- 页面不设置 `body { margin: 0 }`，避免影响整个管理后台。
- 若 VForm 内部根元素没有继承高度，只在当前页面根 class 下使用 `:deep()` 定向补齐，不写全局通配覆盖。
- Element Plus 和 VForm 官方 CSS 保持原始优先级；项目自定义样式只负责容器尺寸和溢出。

## 数据流

本次没有后端数据流。路由激活后 Vue 直接创建 VForm 设计器组件，组件内部管理当前表单 JSON 和设计状态。页面离开时由 Vue 正常卸载，不再需要手动清理子应用或 DOM。

## 错误处理

- 插件或 CSS 无法解析时，Vite 开发服务和生产构建应直接失败，而不在运行时静默降级为空页。
- 页面不再提供“重新加载”按钮。如果设计器运行时异常，使用项目现有 Vue 错误边界和控制台追踪真实原因。

## 验证方案

1. 运行前端 ESLint 和 TypeScript 检查。
2. 运行前端生产构建，确认 VForm 3 UMD/ESM 与 CSS 能被 Vite 正常打包。
3. 启动前端并访问 `/tool/build`。
4. 确认页面打开即显示组件面板、表单画布和属性面板。
5. 确认设计器不覆盖侧边菜单和顶部标签栏，不出现页面级双重滚动条。
6. 拖入至少一个表单组件，确认画布选中和右侧属性编辑正常。
7. 切换到其他标签页再返回，确认布局不泄漏、不重复挂载。

## 风险与约束

- Element Plus CSS 将进入全局样式树。其选择器主要使用 `el-` 前缀，仍需回归检查现有 Naive UI 页面。
- `vform3-builds@3.0.10` 为已发布的打包产物，项目应保持当前锁定版本，本次不顺带升级。
- 如果官方设计器使用固定高度，将通过页面级定向样式修正，而不修改依赖包。

## 验收标准

- `/tool/build` 页面无手动“加载设计器”步骤。
- VForm 3 左、中、右三栏在可用内容区内完整显示。
- 页面无额外 Naive UI 卡片、标题、内边距和固定 700px 高度。
- 设计器内部操作可用，宿主后台布局不受破坏。
- 前端类型检查和生产构建通过。
