# NestJS 后端交互学习手册设计

## 目标

把根目录的 `Nestjs项目架构学习说明.md` 与 `Nestjs后端项目学习梳理交接.md` 融合为无需构建、可离线打开的交互式学习页面。

## 已确认方案

- 根目录单文件 `Nestjs后端项目交互学习手册.html`。
- CSS、JavaScript 和 SVG 图标全部内嵌，不依赖 CDN。
- 左侧阶段导航，中间学习正文，右侧当前阶段学习记录。
- 支持搜索、阶段状态、知识点勾选、笔记、深浅主题和继续学习。
- 使用 `localStorage` 自动保存；支持版本化 JSON 导入、导出和重置。
- 内容覆盖架构总览、请求链路、14 个学习阶段、模块地图、核心概念及 Creator 综合案例。

## 数据流

页面加载 → 读取版本化本地状态 → 渲染进度和上次阶段。用户操作后立即更新状态与总进度；导出时下载 JSON，导入时校验版本和字段后合并并重新渲染。

## 错误与兼容

- 本地存储不可用时进入内存模式并提示。
- 导入文件格式错误时拒绝覆盖现有记录。
- 重置操作二次确认。
- 响应式适配桌面、平板和手机；支持键盘焦点与减少动画偏好。

## 验证

- 静态检查 HTML/CSS/JavaScript 语法和关键元素。
- 浏览器检查布局、导航、搜索、主题、进度、笔记及导入导出。
- 检查刷新后状态仍能恢复。
